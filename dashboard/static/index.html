Personality Vectors

Personality traits in large language models live in a universal 5-dimensional subspace of the activation space. By adding small vectors to hidden states during inference, we can precisely steer personality. Detectable from activations with 100% accuracy, yet completely invisible in generated text.

Key Result

The Activation-Text Paradox

Personality steering encodes 21.8 bits of information in the activation space, enough to specify 3.6 million distinct personality directions with 2-degree angular precision. Yet when the model generates text, RLHF training homogenizes the output so thoroughly that zero bits survive. The personality is real in the model's internal computations but invisible in its words.

5D Personality Subspace

Six RIASEC personality vectors (Realistic, Investigative, Artistic, Social, Enterprising, Conventional) span exactly 5 dimensions across every model tested. The 6th singular value is exactly zero. This is a mathematical necessity since 6 vectors in general position span at most 5 independent directions, but a remarkable empirical confirmation that personality structure is clean and low-dimensional.

Cross-Model Transfer

Personality vectors from one model can be applied to a completely different model, even one 8x larger, and still work perfectly. This is done via a 5D coordinate bridge: extract the personality's coordinates in the source model's 5D space, then reconstruct the vector in the target model's 5D space using its own basis vectors.

Transfer Accuracy

Each bar shows detection accuracy when using personality vectors from the source model to steer the target model. Green bars indicate perfect transfer.

Why does cross-model transfer work?

The 5D personality subspace has the same geometric structure across all models. Via Procrustes alignment (rotation + scaling), we can map any model's personality basis onto any other. Even Llama 1B (a 16-layer model) can provide personality vectors that work on Marin 8B (32 layers) with 100% accuracy. Smaller models encode personality just as cleanly.

Vector Composition

Personality vectors obey linear algebra: adding two vectors produces a blend; subtracting one suppresses it. Self-cancellation (v + (-v)) produces exactly zero personality signal.

Negative Composition Results

Each row shows the result of adding one personality vector while subtracting another. "Boosted" means the positive trait was correctly detected; "Suppressed" means the negative trait was correctly pushed away.

Why this matters

Linear composability means we can create arbitrary personality blends by combining basis vectors with different weights. Self-cancellation (adding a vector and its negative) produces exactly 0.000 personality signal, confirming the vectors are genuine directions, not artifacts.

Temperature x Alpha Sweep

A 2D parameter sweep examining how sampling temperature interacts with steering strength. This reveals the phase boundary between reliable personality detection and noise-dominated regimes.

Detection Accuracy Heatmap

Each cell shows detection accuracy (% of 6 RIASEC traits correctly identified) for a given temperature and alpha combination. Green = 100%, yellow = partial, red = below chance.

How to read this

Temperature controls sampling randomness (higher = more random text). Alpha controls steering strength (higher = stronger personality injection). At low alpha (0.1), high temperature overwhelms the personality signal. But at alpha >= 0.5, detection is robust even at T=1.0. Only at T >= 1.5 with low alpha does accuracy degrade.

Key Findings

  • 100% detection for all temperatures when alpha >= 2.0
  • At standard temperature (T=0.7), alpha >= 0.5 is sufficient for perfect detection
  • Even at T=2.0, alpha >= 2.0 achieves 100%: personality signal overcomes extreme sampling noise

Psychometric Evaluation

We administer standardized personality tests (O*NET Interest Profiler, IPIP-NEO-120) to steered models and measure the logprob differentials. Text-based scoring fails due to RLHF sycophancy, but logprob-based scoring reveals clear personality differentiation.

Logprob-Based Psychometric Scores

Instead of parsing generated text (where the model says "Yes" to everything), we measure the log-probability differential: logP(Yes) - logP(No) for binary items, and the expected value from logP(1..5) for Likert items.

Loading psychometric data...

Why logprobs, not text?

RLHF-trained models are sycophantic: they say "Yes" and agree with everything regardless of personality steering. This makes text-based psychometric scoring useless (all traits score 10/10). But the logprob distribution reveals genuine personality differentiation that is invisible in the argmax text. This is another manifestation of the activation-text paradox.
